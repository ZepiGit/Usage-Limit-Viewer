# Provider artwork

Provider marks identify the corresponding service; they remain the property of their owners.

| Asset | Original source | Preparation |
| --- | --- | --- |
| Claude | [Anthropic PBC's official App Store listing](https://apps.apple.com/us/app/claude-by-anthropic/id6473753684), artwork returned by Apple's lookup API | Original 512 × 512 artwork, lossless PNG encoding; replaces the 32-pixel website favicon |
| OpenAI | [Official brand guidelines](https://openai.com/brand/), Blossom construction-sheet SVG | Unadorned original mark path, white monochrome, proportional framing; Android vector and iOS PNG export |
| Antigravity | [Google press assets](https://antigravity.google/press?app=antigravity), `antigravity-icon__full-color.png` | Original PNG |
| Grok | [Official Grok favicon SVG](https://grok.com/images/favicon.svg) | PNG export preserving paths, colors and composition |
| Kimi | [Official Kimi favicon](https://www.kimi.com/favicon.ico) | PNG encoding of the original icon |

Sources checked on 12 September 2026. Raster assets are bundled locally; displaying account lists and widgets makes no request to these websites.
